Deploy Keepfor.me on your own Cloudflare infrastructure

Keepfor.me is fully open source. You can run the entire serverless stack on your own Cloudflare account for complete data sovereignty, zero subscription fees, and no third-party lock-in.

Five steps to production

Deploy in minutes using the Cloudflare CLI. Review the complete deployment documentation in the GitHub README deployment section.

1

Prerequisites

You will need a Cloudflare account with Workers, D1, R2, Vectorize, and Queues enabled (available on Cloudflare Free and Workers Paid plans). Install Node.js 20+ and Astral uv on your workstation:

# Check your installed tools node -v # v20+ npm -v uv --version
2

Clone repository and install dependencies

Clone the official repository from GitHub and sync Python runtime dependencies:

git clone https://github.com/melcutz/keepfor.me.git cd keepfor.me uv sync
3

Provision Cloudflare edge resources

Run Wrangler to create your D1 database, R2 storage bucket, Vectorize index (768 dimensions for BGE embeddings), and extraction queue:

# 1. Create SQLite D1 database npx wrangler d1 create keepfor-me-db # Copy the returned database_id into your wrangler.jsonc # 2. Create R2 bucket for raw and clean article snapshots npx wrangler r2 bucket create keepfor-me-bucket # 3. Create Vectorize index for semantic vector search npx wrangler vectorize create keepfor-me-index --dimensions=768 --metric=cosine # 4. Create Queue for asynchronous article extraction npx wrangler queues create keepfor-me-queue
4

Apply database schema migrations

Run the SQL migrations to initialize user tables, full-text search virtual tables (FTS5), rate limiting counters, and composite indexing:

npx wrangler d1 migrations apply keepfor-me-db --remote
5

Deploy Worker and claim admin ownership

Deploy your Python FastAPI worker to Cloudflare. Once deployed, open your domain and register immediately: the first account created automatically claims instance ownership and locks public signups.

# Dry-run first to verify bundle size is within limits uvx --from workers-py pywrangler deploy --dry-run # Deploy to your Cloudflare account uvx --from workers-py pywrangler deploy
