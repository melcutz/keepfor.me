Universal Model Context Protocol

Works with Claude, Cursor and any MCP client

Keepfor.me exposes a remote Model Context Protocol (MCP) server over streamable HTTP. Connect your personal vault to modern developer tools and frontier AI agents in seconds.

⚡
Claude Desktop
Anthropic Client (macOS & Windows)

Ask Claude questions grounded in your saved articles, notes, and research. Claude searches your vault via MCP and provides cited responses with exact source links.

claude_desktop_config.json 
{
  "mcpServers": {
    "keepfor": {
      "url": "https://app.keepfor.me/api/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_TOKEN"
      }
    }
  }
}

Core Capabilities

Built for serious collectors and researchers

Four essential pillars make Keepfor.me the most reliable place for everything you discover and learn.

1-Tap Universal Capture

Capture whatever you find in under a second across desktop and mobile. No token friction or broken shares.

  • iOS Safari Shortcut: Uses your existing Safari session directly from the share sheet.
  • Chrome & Edge Extension: Instant keyboard shortcuts and one-click saving while browsing.
  • Android Web Share Target: Integrated right into the Android native share drawer.

Durable Snapshots & Search

Your articles and notes live in a private vault that organizes itself and survives link rot.

  • Permanent Offline Archive: Full original HTML and clean extracted text saved in R2 storage.
  • Hybrid Search: Combines SQLite FTS5 exact matching with Vectorize semantic embeddings.
  • Auto-Tagging Rules: Automatically tags items by domain, keywords, or topics.

Bring Context to Any AI

Connect your personal knowledge vault directly to Claude, Cursor, ChatGPT, or your own agents.

  • Model Context Protocol (MCP): Remote Streamable HTTP server for zero-setup integration.
  • Personal Access Tokens: Secure SHA-256 hashed PATs for API and automated agent access.
  • Ground Truth Citations: Answers cite specific URLs and saved dates from your library.

Distraction-Free Reader Mode

A quiet sanctuary for long-form reading, free of cookie banners, popups, and intrusive ads.

  • Calm Reading Themes: Paper, Warm Sepia, and Night mode with refined typography.
  • Clean Text Extraction: Trafilatura removes ads, social widgets, and navigation clutter.
  • Estimated Read Times: Accurate read time estimates before opening any article.
