Why Moving to Edge Pyodide Changes Read-It-Later Performance

Keepfor.me Engineering · Published in Distributed Systems
Key Takeaway Running Python on Cloudflare Pyodide isolates eliminates cold-boot database connections and delivers sub-second reader views across 300+ edge locations.

Traditional read-it-later tools run on heavy server fleets with centralized relational databases. When an article is opened, queries travel thousands of miles to a single origin region, introducing noticeable lag.

By pairing Cloudflare D1 with R2 object storage and async worker queues, the entire extraction and formatting pipeline executes directly at the edge closest to you.

Job 03

Reciprocal Rank Fusion Hybrid Search

Keyword search misses synonyms. Vector search misses exact identifiers, acronyms, and error codes. Keepfor.me runs both concurrently and combines them mathematically.

  • SQLite FTS5 BM25: Precise exact-match full-text indexing inside Cloudflare D1.
  • Cloudflare Vectorize: Semantic conceptual search using 384-dimensional dense vectors.
  • Concurrent & Bounded: Evaluated with asyncio.gather and strict 5-second timeouts to guarantee fast response times.
Formula: RRF = 1 / (60 + BM25_Rank) + 1 / (60 + Vec_Rank)
Job 04

Your Reading Vault Connected to AI Agents

Keepfor.me is a first-class Model Context Protocol (MCP) server. Give Claude Desktop, Cursor, or your autonomous agent direct, read-only access to your curated research library.

  • Streamable HTTP Transport: No local stdio subprocesses or port proxies required. Native HTTPS JSON-RPC endpoint at /api/mcp.
  • Built-In Agent Tools: search_saved_items, get_item_markdown, and list_tags for comprehensive research retrieval.
  • Secure Token Auth: Authenticated via Personal Access Tokens (kfm_live_*) stored as SHA-256 hashes.

Architecture

Zero Servers. Built entirely on Cloudflare edge primitives.

Keepfor.me leverages Cloudflare's Python Worker runtime (Pyodide), D1, Vectorize, and R2 to deliver a lightning-fast, zero-maintenance personal cloud.

1

Ingest & Queuing

URLs are saved in <50ms. Heavy web extraction is pushed to Cloudflare Queues for asynchronous parsing.

2

Pyodide Extraction

Lazy-loaded Trafilatura and BeautifulSoup extract clean readability text and metadata at the edge.

3

Dual R2 Archival

Full HTML source and formatted Markdown files are written to Cloudflare R2 object storage for durability.

4

D1 & Vectorize

Metadata & FTS5 tokens are written to D1; Workers AI embeds semantic vectors into Vectorize.

Component Technology Design Rationale & Latency
Runtime Cloudflare Python Worker (Pyodide) FastAPI application with 250–350ms warm response and zero server instances to patch.
Database Cloudflare D1 (SQLite + FTS5) Serverless edge database with composite indexes and sub-roundtrip RPC batching.
Snapshot Storage Cloudflare R2 Object Storage S3-compatible zero egress cost storage for immutable Markdown and HTML article backups.
Search Index SQLite FTS5 + Cloudflare Vectorize Reciprocal Rank Fusion merges BM25 text match with 384-dimensional dense semantic vectors.
Agent Protocol Model Context Protocol (JSON-RPC) Streamable HTTP server at /api/mcp for direct consumption by LLM coding tools.

FAQ

Frequently Asked Questions

How does Keepfor.me differ from Pocket or Omnivore?

Keepfor.me is self-hosted on your own Cloudflare account. There are no venture-backed subscription paywalls, no analytics tracking, and no risk of shutdown. Furthermore, Keepfor.me offers native Model Context Protocol (MCP) support, enabling AI agents like Claude to directly read your personal library.

Does it cost anything to run on Cloudflare?

For personal usage, Keepfor.me costs $0/month. Cloudflare's free tier includes 100,000 Worker requests/day, 5GB of D1 SQLite storage, 10GB of R2 storage with free egress, and free Vectorize index queries.

Can I use Keepfor.me on my phone without an app store download?

Yes. Keepfor.me is a progressive web app (PWA). On Android, it implements the Web Share Target API. On iOS, it uses a 1-tap Apple Shortcut and clipboard auto-detection, providing an app-like experience directly through Safari.

How do I connect Claude Desktop or Cursor?

Go to Settings in your Keepfor.me instance, generate a Personal Access Token (PAT), and copy the JSON snippet from the MCP tab. Paste it into your claude_desktop_config.json or .cursor/mcp.json. Your assistant can now query your saved reading list anytime.
