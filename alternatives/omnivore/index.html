🌱 Omnivore Alternative & Migration Guide

Omnivore Alternative: Open-Source Reading That Stays Yours

Hosted Omnivore shut down in November 2024 when its team joined ElevenLabs. Here is how to import your Omnivore export zip into Keepfor.me, self-host on serverless Cloudflare edge primitives without container bloat, or run on managed cloud plans with 46 MCP tools.

Migration & Architecture Guide · November 2026 Back to Homepage

People searching for an Omnivore alternative usually share the same backstory: the hosted Omnivore app shut down in November 2024 when its team joined ElevenLabs. Exports stayed open until November 15, 2024, and then the hosted data was deleted. Even though Omnivore's code was open source, running its self-hosted stack required multiple containers, Postgres, Redis, and background workers that few individual readers wanted to maintain.

Readers who gravitated toward Omnivore cared about a specific set of values: open-source code, a clean distraction-free reading environment, highlights and notes, and complete ownership of their saved library. When evaluating an Omnivore alternative, those structural guarantees matter more than marketing promises. A replacement should be simple to self-host, honest about what its importer handles, and transparent about how it sustains itself.

Importing your Omnivore archive into Keepfor.me

Omnivore's official export was a .zip archive containing batched metadata_*.json files (such as metadata_0_to_20.json) plus saved article snapshots in content/*.html and exported notes and highlights in highlights/*.md. Keepfor Cloud's importer (_prepare_zip_bookmarks and its Omnivore metadata JSON parser) reads that export directly:

  • What carries over (links, titles, and labels): Upload your Omnivore metadata_*.json files or your Omnivore export .zip containing metadata_*.json and content/*.html. Keepfor reads each entry's url, title, and labels (mapping Omnivore labels to Keepfor tags), deduplicates by URL, and queues every link for fresh extraction and permanent dual snapshots (raw.html and clean.html) in Cloudflare R2.
  • What does not carry over: Keepfor's bookmark importer does not import Omnivore's highlights/*.md files as character-anchored article highlights, and it does not import pre-rendered content/*.html files in place of fetching its own R2 snapshots. (If your Omnivore .zip still includes highlights/*.md, upload the metadata_*.json files directly or remove the highlights/*.md files from the zip first, because zips containing .md files are routed to the Markdown notes importer instead of the bookmark importer.)
  • Standard bookmark and note formats: Keepfor also imports Netscape Bookmark HTML (.html) from browsers and Pocket, CSV bookmark files, Markdown note zips up to 50 MB, Google Keep Takeout zips, and Evernote .enex files.

Every bulk upload runs asynchronously through Cloudflare Queues in batches of 25 items, so importing hundreds of saved articles never times out your request. Duplicate URLs are skipped automatically, and each upload produces a persistent status record showing imported counts, skipped duplicates, and any parse errors.

Why serverless self-hosting beats multi-container stacks

One of the hardest lessons in open-source read-it-later software is that an open license only protects you if you can actually afford and maintain the self-hosted deployment. Traditional self-hosted stacks often require a virtual private server, multiple Docker containers, a background worker fleet, and an external database.

Keepfor.me is licensed under AGPL-3.0-only and takes a deliberately thinner path: it runs entirely on serverless Cloudflare edge primitives:

  • Cloudflare Python Workers: FastAPI application running at the edge with zero idle compute cost.
  • D1 SQLite with FTS5: Serverless relational database with native BM25 full-text keyword indexing.
  • Cloudflare R2 Object Storage: Stores both the original raw HTML (raw.html) and sanitized reader HTML (clean.html) so your archive survives link rot.
  • Cloudflare Vectorize: 768-dimension semantic vector index (bge-base-en-v1.5) for meaning-based search.
  • Cloudflare Queues: Resilient background extraction via trafilatura with visible status tracking (Extracting..., content, or explicit failure reason such as HTTP 403).

You can deploy your own private single-tenant instance in five CLI steps (see our Self-Host Guide). The first account registered automatically claims admin ownership and locks public signups.

Distraction-free reading, highlights, and 46 MCP tools

Keepfor pairs a calm human reading experience with a first-class AI interface:

  • Reader Sanctuary: Read long-form articles in Paper, Warm Sepia, or Night themes with Sans, Serif, or Mono typography and adjustable font sizing.
  • Highlights and Collections: Anchor highlights to exact character offsets inside saved text, attach personal notes and colors, and group items into named collections or hierarchical tags (such as work/research).
  • Trash Protection: Deleting an item in the UI or via an AI agent moves it to a 30-day restorable Trash while keeping the database row, R2 snapshots, and vector embeddings intact. Only "Delete forever" in the Trash view permanently removes data.
  • Remote MCP Server (46 tools): Keepfor exposes 46 MCP tools over Streamable HTTP at https://app.keepfor.me/api/mcp. Connect Claude Desktop, Claude Code, Cursor, or opencode using a Bearer Personal Access Token (with read-only or write scope) to search passages, summarize unread saves, suggest tags, or save new links from chat.

Why sustainable pricing matters
