Karakeep vs Keepfor.me: Choosing Your Personal Vault

Evaluating Karakeep and Keepfor.me? Here is how Keepfor approaches visual card browsing, serverless Cloudflare edge self-hosting, hybrid semantic search, and native MCP integration.

Architecture Guide · November 2026 Back to Homepage

If you are comparing Karakeep and Keepfor.me, you are looking at two open-source (AGPL-3.0) self-hostable bookmark and read-it-later tools that take very different infrastructure paths. Karakeep (formerly known as Hoarder) is a self-hosted "bookmark-everything" app for links, notes, images, and PDFs. Its standard deployment runs on a server via Docker Compose using three containers (the Karakeep web app, Meilisearch for full-text search, and headless Chrome for page archival) with optional AI tagging through OpenAI or local Ollama models. Keepfor.me is built for distraction-free reading, hybrid semantic search, and an AI context vault (46 MCP tools) running entirely on serverless Cloudflare edge primitives with zero containers to maintain.

Visual density and calm long-form reading

Keepfor's interface was designed with high-density browsing and visual polish in mind, combining visual card covers, multi-view layouts, and a pinned top shelf with a quiet reader view:

  • Multi-view library layouts: Switch between Grid, Compact List, and Magazine card views, with a pinned top shelf (pin_item) for active research and tag chips for instant filtering.
  • Distraction-free reader mode: Every saved article is extracted with trafilatura and presented in Paper, Warm Sepia, or Night mode with customizable fonts (Sans, Serif, Mono) and font sizes.
  • Dual HTML snapshots: Keepfor stores both the original HTML (raw.html) and sanitized reader HTML (clean.html) in Cloudflare R2 object storage, with visible extraction states (Extracting..., content, or explicit failure reasons).
  • Highlights, notes, and collections: Save quick notes and snippets alongside web links, highlight passages anchored by character offsets, and organize items with collections and hierarchical tags (such as work/research).

Serverless Cloudflare edge vs Docker Compose containers

When self-hosting a personal library, the biggest operational question is what infrastructure you want to run. Karakeep's official Docker Compose setup runs a persistent Node.js web container, a Meilisearch container, and an Alpine headless Chrome container on your own VPS or home server. Keepfor.me is also licensed under AGPL-3.0-only, and runs without Docker containers or always-on virtual machines:

If you already run a home server or VPS and prefer container-based self-hosting, evaluate whether a container stack fits your setup better. If you prefer serverless edge infrastructure that scales to zero on Cloudflare's free tier (or want a managed cloud vault with zero maintenance), Keepfor is built specifically for that model.

AI context vault: hybrid search and 46 MCP tools

Keepfor treats AI assistants as first-class readers of your library alongside humans:

  • Hybrid search (RRF): Combines SQLite FTS5 BM25 keyword matching with Cloudflare Vectorize semantic embeddings concurrently. If an AI binding is ever slow, search degrades gracefully to keyword results rather than hanging.
  • 46 MCP tools over Streamable HTTP: Point Claude Desktop, Claude Code, Cursor, or opencode at https://app.keepfor.me/api/mcp with a Bearer Personal Access Token. Your assistant can search passages (search_passages), read full articles in token-efficient chunks (read_item), save batches of up to 50 URLs (save_urls), audit duplicate links and dead fetches (find_cleanup), and manage tags and collections.
  • Built-in safety rails: Bulk MCP tools default to dry_run=true so an agent previews changes before writing, tokens support read-only or write scopes, and delete_item moves items to a 30-day restorable Trash instead of permanently deleting data.

Managed pricing and quotas

If you prefer not to manage Wrangler bindings or D1 migrations yourself, Keepfor Cloud offers a 14-day free trial (no credit card required, 50 AI summaries and 20 ask-your-library queries per month) and two paid tiers:

  • Personal ($5/month or $55/year): Hosted MCP, hybrid semantic search, unlimited bookmarks and permanent R2 snapshots, 150 AI summaries per month, and 50 ask-your-library queries per month.
  • Pro ($9/month or $90/year): Everything in Personal, plus higher AI quota and hosting scale: 1,000 AI summaries per month, 500 ask-your-library queries per month, and priority asynchronous extraction queue.
